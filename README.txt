# Drishti Public School Website

This is a responsive static school website ready for free hosting.

## Included
- Home, About, Facilities, Admission, Gallery and Contact sections
- School logo
- Responsive mobile design
- Online admission enquiry form that opens WhatsApp to 9709767598
- Call buttons for school contacts

## Free public publishing
The files can be published with GitHub Pages or another static hosting service.
Upload `index.html`, `style.css`, and the `assets` folder together.

## Before publishing
You may want to add:
- School photographs in Gallery
- School registration/UDISE details, if applicable
- School notices
- Google Maps location
- A dedicated Google Form if you want admission responses saved in a spreadsheet
